# 🛡️ SMS Fraud Detector
### Система обнаружения мошеннических SMS на русском и кыргызском языках

## 1. О проекте

SMS Fraud Detector — система на основе машинного обучения, предназначенная для обнаружения мошеннических SMS-сообщений.

### Возможности
- Анализ SMS на русском и кыргызском языках.
- Обнаружение смешанных языков.
- Распознавание обфускации: цифры вместо букв, пробелы и точки внутри слов.
- Распознавание латиницы вместо кириллицы.
- Оценка риска от 0 до 100.
- Объяснение подозрительных признаков.
- Рекомендации пользователю.
- Массовая проверка SMS через CSV.
- История проверок.
- Проверка SMS через Telegram-бота.

## 2. Требования

Для запуска необходимы:
- Python 3.10 или выше.
- Интернет для установки библиотек.
- Telegram для использования бота.

Обученная ML-модель уже включена в проект. Повторно обучать её не требуется.

## 3. Установка

Откройте терминал в папке проекта.

Создайте виртуальное окружение.

**Ubuntu / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## 4. Запуск веб-приложения

Для работы веб-приложения необходимо запустить два компонента.

### Шаг 1. Backend (FastAPI)

Откройте первый терминал:

```bash
uvicorn api:app --reload
```

API будет доступен по адресу:

http://127.0.0.1:8000

Проверка состояния:

http://127.0.0.1:8000/health

Документация API:

http://127.0.0.1:8000/docs

### Шаг 2. Frontend (Streamlit)

Откройте второй терминал в папке проекта.

Активируйте виртуальное окружение.

Ubuntu / Linux:

```bash
source venv/bin/activate
```

Windows:

```bash
venv\Scripts\activate
```

Запустите интерфейс:

```bash
streamlit run app.py
```

Откройте в браузере:

http://localhost:8501

**Веб-приложение готово к использованию!**

## 5. Запуск Telegram-бота

Проект поддерживает проверку SMS непосредственно через Telegram.

Токен Telegram-бота хранится в файле `.env` в корневой папке проекта.

### Запуск

Откройте третий терминал в папке проекта.

Активируйте виртуальное окружение:

```bash
source venv/bin/activate
```

Установите необходимые зависимости (если ещё не установлены):

```bash
pip install -r requirements.txt
```

Запустите Telegram-бота:

```bash
python -m bot.telegram_bot
```

После запуска:
1. Откройте Telegram.
2. Найдите своего бота.
3. Отправьте команду `/start`.
4. Отправьте SMS для проверки.
5. Получите оценку риска и рекомендации.

**Важно:** файл `.env` должен находиться в корневой папке проекта. Не публикуйте его содержимое в GitHub.

## 6. Примеры проверки SMS

**Обычное сообщение:**

```text
Ваш баланс успешно пополнен на 300 сом. Спасибо!
```

**Подозрительное сообщение:**

```text
Ваш аккаунт будет заблокирован!
Срочно отправьте код из SMS для подтверждения.
```

**Сообщение с обфускацией:**

```text
Срoчнo! Вaш aккaунт зaблoкирoвaн. Oтпpaвьтe кoд!
```

## 7. Массовая проверка SMS

В веб-приложении перейдите во вкладку «Массовая проверка CSV».

Загрузите CSV-файл со столбцом `text`.

Система проверит сообщения и сформирует таблицу с результатами. Результаты можно скачать в формате CSV.

## 8. Оценка качества модели

Для проверки качества модели выполните:

```bash
python evaluate.py
```

Для запуска автоматических тестов:

```bash
python -m unittest discover -s tests -v
```

## 9. Уровни риска

| Уровень | Оценка |
|---|---|
| LOW | Менее 30 |
| MEDIUM | От 30 до 64 |
| HIGH | От 65 до 100 |

## 10. Важная информация

- Модель уже обучена и готова к использованию.
- Для веб-приложения API-ключ не нужен.
- Для Telegram-бота необходим токен от BotFather.
- Ссылки из сообщений автоматически не открываются.
- Официальные домены учитываются как дополнительный сигнал.
- Результат является оценкой риска, а не абсолютной гарантией безопасности.
