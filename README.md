# 🛡️ SMS Fraud Detector
### Система обнаружения мошеннических SMS на русском и кыргызском языках

## 1. О проекте

**SMS Fraud Detector** — система на основе машинного обучения, предназначенная для обнаружения мошеннических SMS-сообщений.

Проект помогает выявлять подозрительные сообщения, оценивать уровень риска и объяснять пользователю потенциальные угрозы.

### Возможности

- Анализ SMS на русском и кыргызском языках.
- Обнаружение смешанных языков.
- Распознавание обфускации: цифры вместо букв, пробелы и точки внутри слов.
- Распознавание латиницы вместо кириллицы.
- Оценка риска от 0 до 100.
- Объяснение подозрительных признаков.
- Рекомендации пользователю.
- Массовая проверка SMS через CSV.
- История проверок.
- Проверка SMS через Telegram-бота.

## 2. Требования

Для запуска проекта необходимы:

- Python 3.10 или выше.
- Интернет для установки библиотек.
- Интернет для работы Telegram-бота.

Обученная ML-модель уже включена в проект. Повторно обучать её не требуется.

## 3. Установка

Откройте терминал в папке проекта.

Создайте виртуальное окружение.

**Ubuntu / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## 4. Запуск проекта

Для удобства предусмотрен единый файл запуска `start.py`.

Он автоматически запускает три компонента:

1. **FastAPI** — серверная часть и API.
2. **Streamlit** — пользовательский веб-интерфейс.
3. **Telegram Bot** — проверка SMS через Telegram.

После установки зависимостей выполните:

```bash
python start.py
```

После запуска компоненты будут доступны по следующим адресам:

| Компонент | Адрес |
|---|---|
| Веб-приложение (Streamlit) | http://localhost:8501 |
| FastAPI | http://127.0.0.1:8000 |
| Документация API | http://127.0.0.1:8000/docs |
| Проверка состояния API | http://127.0.0.1:8000/health |

### Использование Telegram-бота

1. Откройте Telegram.
2. Найдите бота по имени пользователя, указанному командой проекта.
3. Отправьте команду `/start`.
4. Отправьте SMS для проверки.
5. Получите результат анализа, оценку риска и рекомендации.

Для остановки всех компонентов нажмите `Ctrl + C` в терминале.

**Примечание:** если порты 8000 или 8501 уже заняты, остановите предыдущие процессы перед запуском.

## 5. Примеры проверки SMS

**Обычное сообщение:**

```text
Ваш баланс успешно пополнен на 300 сом. Спасибо!
```

**Подозрительное сообщение:**

```text
Ваш аккаунт будет заблокирован!
Срочно отправьте код из SMS для подтверждения.
```

**Сообщение с обфускацией:**

```text
Срoчнo! Вaш aккaунт зaблoкирoвaн. Oтпpaвьтe кoд!
```

## 6. Массовая проверка SMS

В веб-приложении перейдите во вкладку «Массовая проверка CSV».

Загрузите CSV-файл со столбцом `text`.

Система проверит сообщения и сформирует таблицу с результатами. Результаты можно скачать в формате CSV.

## 7. Оценка качества модели

Для проверки качества модели выполните:

```bash
python evaluate.py
```

Для запуска автоматических тестов:

```bash
python -m unittest discover -s tests -v
```

## 8. Уровни риска

| Уровень | Оценка |
|---|---|
| LOW | Менее 30 |
| MEDIUM | От 30 до 64 |
| HIGH | От 65 до 100 |

## 9. Важная информация

- Модель уже обучена и готова к использованию.
- Для веб-приложения API-ключ не нужен.
- Telegram-бот использует настроенный токен.
- Ссылки из сообщений автоматически не открываются.
- Официальные домены учитываются как дополнительный сигнал.
- Результат является оценкой риска, а не абсолютной гарантией безопасности.
